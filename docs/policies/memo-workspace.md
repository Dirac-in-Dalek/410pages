# 책과 구절 메모 Policy

## 확정 정책

- 책 화면의 구절 메모는 왼쪽 서재 트리와 같은 고정 영역에 표시하며, 메모 패널이 열리면 서재 트리를 대신한다.
- 열린 구절을 다시 누르거나 패널 밖을 누르거나 `Escape`를 누르면 구절 메모 패널을 닫는다.
- 다른 구절을 누르면 패널을 닫지 않고 해당 구절의 메모로 바꾼다.
- 구절 메모는 기존처럼 여러 개를 둘 수 있으며 추가·수정은 전송 버튼이나 `Enter`로 확정한다. 줄바꿈은 `Shift+Enter`를 사용하고 한글 조합 중 `Enter`는 저장으로 처리하지 않는다.
- 책 전체 메모는 책마다 하나이며 오른쪽 고정 영역에서 편집한다.
- 책 전체 메모는 입력이 멈춘 뒤 800ms에 자동 저장한다.
- 책 전체 메모 우측 하단에는 자동저장과 같은 저장 경로를 즉시 실행하는 `저장` 버튼을 항상 표시한다.
- 데스크톱에서는 책 전체 메모 패널을 완전히 접을 수 있고, 책 화면 상단 우측의 메모 버튼으로 다시 펼친다.
- 데스크톱의 접힘 상태는 현재 접속 중 모든 책에 유지하며, 패널이 접혀 있어도 진행 중인 자동저장은 계속한다.
- 저장 전 내용과 저장 실패 내용은 계정과 책별 브라우저 임시 저장소에 보관하고 서버 저장 성공 후 제거한다.
- 모바일에서는 구절 메모와 책 전체 메모를 각각 하단 시트로 열며 한 번에 하나만 표시한다.
- 같은 저자 안에서 동명 책을 병합할 때 대상 책 메모를 먼저 둔다. 두 메모가 모두 있으면 빈 줄·구분선·빈 줄 뒤에 원본 책 메모를 붙인다.
- 병합할 두 메모의 앞뒤 공백을 제거한 내용이 같으면 대상 책 메모 하나만 유지한다.
- 저자 병합 과정에서 동명 책이 합쳐질 때도 같은 책 메모 병합 규칙을 적용한다.
