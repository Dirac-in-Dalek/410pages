## 확정 정책

### 2026-10-07 데스크톱 책 읽기 화면

- 1024px 이상 책 상세 화면은 왼쪽 문장별 댓글, 가운데 제목·인용문, 오른쪽 책 메모를 하나의 폭이 제한된 읽기 묶음으로 배치한다. 인용문이 가장 넓고 책 메모, 문장별 댓글 순으로 좁게 두며 세 열을 같은 폭으로 만들지 않는다.
- 세 열의 보이는 글 영역은 댓글:본문:메모를 1:2:1로 계산한다. 이전에 검토한 3:4:3은 현재 기준이 아니다.
- 현재 단계에서는 폭이 제한된 읽기 묶음 안에서 1:2:1을 유지한다. 더 넓은 화면에서 실제 가용 CSS 폭, 서재·메모 상태, 사용자 글자 설정, zoom·DPR에 따라 글자 크기·본문 행 길이·양쪽 열·간격·바깥 여백·조작 밀도를 어떻게 함께 바꿀지는 다음 넓은 화면 설계에서 비교하고 사용자 선택 뒤 확정한다. 4K는 검증할 여러 크기 중 하나다.
- 제목·저자·목록 조작의 글자 시작선은 가운데 인용문 글자 시작선과 맞춘다. 인용문 양쪽의 댓글·메모까지 글자 영역 사이 거리는 같은 값으로 계산한다.
- 문장별 댓글은 해당 인용문과 같은 행에서 함께 스크롤한다. 책 메모는 오른쪽 읽기 열에서 독립적으로 스크롤한다.
- 책 메모 열은 책 화면의 자연스러운 상단에서 시작한다. 메모 본문 첫 줄을 첫 인용문 상단에 맞추기 위한 별도 시작 여백은 두지 않는다.
- 책 메모는 카드형 고정 사이드바 대신 본문과 어울리는 서체·크기·행간의 긴 글로 표시한다. 저장 중·저장됨·실패 상태와 실패 재시도·복구 초안 저장 조작, 책별 초안과 저장 직렬화는 유지한다.
- 상단 `메모` 버튼으로 책 메모 열을 접고 펼친다. 접어도 편집기를 제거하지 않으며 입력 내용·초안·자동 저장과 인용문 위치를 유지한다.
- 데스크톱 읽기 화면의 메모 접기·펼치기 버튼은 메모 열 헤더 오른쪽 끝에 둔다. 접힌 상태에도 메모 헤더와 버튼은 보이고 조작할 수 있다.
- 세 열과 서재를 함께 둘 공간이 부족하면 서재를 자동으로 접는다. 메모 열을 공간 부족만으로 자동으로 닫지 않으며, 사용자의 서재·메모 수동 조작을 유지한다.
- 서재와 메모 열의 드래그·키보드 폭 조절 및 같은 브라우저의 폭 기억은 유지하되, 실제 읽기 묶음 안에서는 인용문을 과도하게 줄이지 않는 가용 폭 계산을 적용한다.
- 모바일의 댓글·책 메모 하단 시트 동작은 유지한다.

- 인용문 메모를 나란히 비교할 때는 패널 전환 중 원문 기준 위치를 유지한다. 일반 읽기에서는 현재 가용 영역에 본문을 배치한다. 2026-09-13 일괄 UI 개선에 따른 구현 판단이다.

- 서재 패널 접기와 인용문 메모 전체 펼치기는 독립적으로 조작한다.

- 인용문 옆 저장된 댓글과 댓글 입력칸의 글자 시작선을 맞춘다.

- 인용문 메모 전체 펼치기·접기는 목록 위의 단일 버튼에서 조작한다. 각 행에는 해당 인용문의 메모 조작만 둔다.
- 공간이 충분한 데스크톱에서는 인용문 댓글과 책 전체 메모를 동시에 사용한다. 책 전체 메모를 열거나 그 안을 클릭했다는 이유로 댓글을 닫지 않는다.

- 양쪽 데스크톱 패널은 232~960px 범위에서 경계선을 드래그해 너비를 조절하고, 같은 브라우저에서 너비를 기억한다.
- 댓글은 왼쪽 패널 끝부터 인용문 본문 시작까지의 여백 가운데에 배치한다. 왼쪽 패널을 접어도 인용문 위치는 유지하며, 댓글만 넓어진 여백 가운데로 이동한다. 댓글 입력창은 해당 칸 하단에 유지한다.
- 데스크톱 댓글 사이는 선 대신 여백으로 구분한다. 인용문 사이의 선은 원문 영역에만 표시한다.

- 인용문 옆 댓글 입력창은 화면 하단이 아니라 해당 댓글 칸의 하단에 붙인다.
- 인용문 옆 댓글에서 작성 날짜와 `댓글 · 쪽수` 제목을 표시하지 않는다.

- 인용문 옆에 나란히 표시하는 댓글 본문은 왼쪽 정렬한다.

- 넓은 데스크톱에서 인용문 댓글(구절 메모)은 왼쪽 홈·서재 패널을 재사용하지 않고, 대상 인용문 왼쪽에 인용문 상단과 맞춰 표시한다.
- 모바일의 인용문 댓글 표시 방식은 현재 동작을 유지한다.
- 재설계 확정: 데스크톱에서 댓글을 인용문 왼쪽에 둘 공간이 부족하면 홈·서재 패널을 자동으로 접어 공간을 확보한다.
- 홈을 접어도 댓글·인용문·전체 메모 공간이 부족하면 전체 메모 패널을 자동으로 접는다. 이 규칙은 2026-10-07 데스크톱 세 열 읽기 화면에서 메모를 자동으로 닫지 않는 규칙으로 대체했다.
- 자동 접힘 후 홈을 수동으로 펼치면 열린 인용문 댓글을 닫는다.
- 재설계 확정: 댓글은 대상 인용문과 함께 스크롤한다. 댓글만 따로 스크롤하거나 화면에 고정하지 않는다.
- 댓글의 내부 여백은 작게 유지한다. 가로 배치는 2026-09-09 승인한 왼쪽 여백 중앙 정렬을 따른다.
- 사용자가 높이 선택 1안을 승인했다. 원문과 댓글 중 긴 쪽에 맞춰 해당 행만 늘린다. 전체 펼치기는 저장된 댓글을 표시하고 입력창은 선택한 인용문에만 연다.
