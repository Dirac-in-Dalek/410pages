# 책과 구절 메모 Policy

## 확정 정책

- 우측 책 메모 패널을 접거나 펼쳐도 인용문 위치를 유지한다.

- 책 화면에서 좌측 홈 패널을 접으면 모든 인용문의 저장된 댓글을 함께 펼친다.

- 인용문 옆 저장된 댓글과 댓글 입력칸의 글자 시작선을 맞춘다.

- 댓글 전체 펼치기·접기는 책 제목이 아니라 인용문 아래 `메모 N` 옆에서 조작한다.
- 공간이 충분한 데스크톱에서는 인용문 댓글과 책 전체 메모를 동시에 사용한다. 책 전체 메모를 열거나 그 안을 클릭했다는 이유로 댓글을 닫지 않는다.

- 양쪽 데스크톱 패널은 232~960px 범위에서 경계선을 드래그해 너비를 조절하고, 같은 브라우저에서 너비를 기억한다.
- 댓글은 왼쪽 패널 끝부터 인용문 본문 시작까지의 여백 가운데에 배치한다. 왼쪽 패널을 접어도 인용문 위치는 유지하며, 댓글만 넓어진 여백 가운데로 이동한다. 댓글 입력창은 해당 칸 하단에 유지한다.
- 데스크톱 댓글 사이는 선 대신 여백으로 구분한다. 인용문 사이의 선은 원문 영역에만 표시한다.

- 인용문 옆 댓글 입력창은 화면 하단이 아니라 해당 댓글 칸의 하단에 붙인다.
- 인용문 옆 댓글에서 작성 날짜와 `댓글 · 쪽수` 제목을 표시하지 않는다.

- 인용문 옆에 나란히 표시하는 댓글 본문은 왼쪽 정렬한다.

- 넓은 데스크톱에서 인용문 댓글(구절 메모)은 왼쪽 홈·서재 패널을 재사용하지 않고, 대상 인용문 왼쪽에 인용문 상단과 맞춰 표시한다.
- 모바일의 인용문 댓글 표시 방식은 현재 동작을 유지한다.
- 재설계 확정: 데스크톱에서 댓글을 인용문 왼쪽에 둘 공간이 부족하면 홈·서재 패널을 자동으로 접어 공간을 확보한다.
- 홈을 접어도 댓글·인용문·전체 메모 공간이 부족하면 전체 메모 패널을 자동으로 접는다.
- 자동 접힘 후 홈을 수동으로 펼치면 열린 인용문 댓글을 닫는다.
- 재설계 확정: 댓글은 대상 인용문과 함께 스크롤한다. 댓글만 따로 스크롤하거나 화면에 고정하지 않는다.
- 댓글의 내부 여백은 작게 유지한다. 가로 배치는 2026-09-09 승인한 왼쪽 여백 중앙 정렬을 따른다.
- 사용자가 높이 선택 1안을 승인했다. 원문과 댓글 중 긴 쪽에 맞춰 해당 행만 늘린다. 전체 펼치기는 저장된 댓글을 표시하고 입력창은 선택한 인용문에만 연다.
- 원문과 번역문을 비교할 수 있도록 여러 인용문의 댓글을 한 번에 펼치고 다시 접는 기능을 제공한다. 각 댓글은 해당 인용문과 나란히 표시한다.
- 개별 입력창은 열린 구절을 다시 누르거나 패널 밖을 누르거나 `Escape`를 누르면 구절 메모 패널을 닫는다.
- 다른 구절을 누르면 입력 대상을 해당 구절로 바꾼다. 전체 댓글 표시는 별도 조작으로 펼치고 접는다.
- 구절 메모는 기존처럼 여러 개를 둘 수 있으며 추가·수정은 전송 버튼이나 `Enter`로 확정한다. 줄바꿈은 `Shift+Enter`를 사용하고 한글 조합 중 `Enter`는 저장으로 처리하지 않는다.
- 책 전체 메모는 책마다 하나이며 오른쪽 고정 영역에서 편집한다.
- 책 전체 메모 입력 시 박스 둘레의 파란 포커스 외곽선을 표시하지 않는다.
- 책 전체 메모는 입력이 멈춘 뒤 800ms에 자동 저장한다.
- 책 전체 메모 우측 하단에는 자동저장과 같은 저장 경로를 즉시 실행하는 `저장` 버튼을 항상 표시한다.
- 데스크톱에서는 책 전체 메모 패널을 완전히 접을 수 있고, 책 화면 상단 우측의 메모 버튼으로 다시 펼친다.
- 데스크톱의 접힘 상태는 현재 접속 중 모든 책에 유지하며, 패널이 접혀 있어도 진행 중인 자동저장은 계속한다.
- 저장 전 내용과 저장 실패 내용은 계정과 책별 브라우저 임시 저장소에 보관하고 서버 저장 성공 후 제거한다.
- 모바일에서는 구절 메모와 책 전체 메모를 각각 하단 시트로 열며 한 번에 하나만 표시한다.
- 같은 저자 안에서 동명 책을 병합할 때 대상 책 메모를 먼저 둔다. 두 메모가 모두 있으면 빈 줄·구분선·빈 줄 뒤에 원본 책 메모를 붙인다.
- 병합할 두 메모의 앞뒤 공백을 제거한 내용이 같으면 대상 책 메모 하나만 유지한다.
- 저자 병합 과정에서 동명 책이 합쳐질 때도 같은 책 메모 병합 규칙을 적용한다.
