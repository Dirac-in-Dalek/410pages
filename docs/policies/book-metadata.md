# 도서 표지·목차 연결 Policy

## 확정 정책

- YES24를 이용해 책의 표지와 실제 목차를 조회한다.
- 제목·저자가 일치하고 표지가 있을 때만 자동 연결한다.
- 비교 시 공백 및 저자·역자 역할 표기를 정리한다. 권수·판본의 차이는 표기 차이로 제거하지 않는다.
- 없거나 후보가 애매하면 기존 CSS 책 모양을 유지한다.
- 예외: `광마회귀`처럼 권수가 지정되지 않은 시리즈는 해당 저자의 1권 표지를 사용한다.
- 연결 결과는 같은 브라우저에 기억하여 재사용한다. 서버 DB에 표지 연결을 저장하는 방식은 선택하지 않았다.
- 책을 열면 실제 목차를 자동으로 가져온다. 목차가 없으면 비워 두고 직접 챕터를 추가한다.
- 챕터 UX는 [책 목차와 챕터 Policy](./book-chapters.md)를 따른다. 제목 아래 별도 목차 접기 UI를 고르는 이전 질문은 인수인계의 확정된 책 본문형 UX로 대체한다.
- 같은 제목·저자라도 판본이 다르면 별도 책으로 관리한다.

## 남은 사용자 결정

- 목차 원문의 계층·시작 페이지 변환과 기존 챕터 병합은 챕터 Policy의 미결정 항목에 따라 확정한다.
