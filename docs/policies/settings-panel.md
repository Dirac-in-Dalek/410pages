# 설정 패널 Policy

## 확정 정책

- 설정 패널은 `프로필 → 읽기 → 화면 → 계정` 순서의 컴팩트 설정 목록으로 구성한다.
- 데스크톱은 기존 420~460px 우측 패널을, 모바일은 기존 전체 폭 하단 시트를 유지한다.
- 섹션은 하나의 낮은 표면과 얇은 행 구분선을 사용하며 중첩 카드와 과도한 그림자를 사용하지 않는다.
- 프로필 사진은 56~64px로 표시한다. 사용자가 D안을 선택하여 사진 오른쪽 아래에 카메라 아이콘 버튼을 겹쳐 배치한다. 보이는 원은 32px, 실제 터치 영역은 44px 이상이며 `사진 변경` 접근성 이름과 툴팁을 제공한다. (2026-10-08 사용자 선택, 사진 아래 텍스트 버튼 배치를 대체)
- 프로필 원본 이미지는 5MB 이하만 편집기에 진입할 수 있다.
- 이름은 `수정` 버튼 바로 옆에서 오른쪽 정렬한 텍스트로 표시한다. `수정`을 누르면 오른쪽 정렬한 인라인 입력과 `저장·취소`를 제공한다.
- 이름과 프로필 사진만 `저장 중·저장됨·실패` 상태를 조작부 가까이에 표시한다.
- 글자 크기는 슬라이더 하나로 선택하고 현재 값을 `11pt`처럼 숫자로 표시한다. `작게·보통·크게` 버튼과 `맞춤` 분류 문구는 제거한다. 포인터·키보드로 조작할 수 있고 모바일 터치 대상은 최소 44px다. (2026-10-07 후속 사용자 교정)
- 사용자가 지정했던 작게 8pt·보통 11pt·크게 15pt 프리셋은 숫자 표시로 대체한다. 기본값은 이후 사용자가 지정한 12pt다. 범위 안의 기존 맞춤값은 유지하고, 첫 화면·설정·로컬/서버 설정 정규화가 같은 기준을 사용한다. (2026-10-07 후속 사용자 지정)
- 사용자가 일반적인 노트북의 글자 조절 범위를 7~20pt로 지정했다. 1024 기준 본문 크기에 적용하고 1pt 간격·화면 폭에 따른 기존 확대 계산은 유지한다. 범위 밖의 이전 저장값은 7~20pt로 제한한다. (2026-10-07 후속 사용자 지정)
- `인용구 너비` 조절 칸은 제거한다. 책 상세의 너비는 화면 읽기 영역의 비율로 자동 계산하며 글자 선택과 독립적이다. 기존 너비 저장 필드는 이전 데이터 호환을 위해 보존하되 새 책 상세 계산에서는 참조하지 않는다. (2026-10-07 사용자 교정)
- 슬라이더 변경은 화면과 로컬 설정에 즉시 반영하고 연속 조작의 서버 저장을 묶는다. 기존 계정 분리와 로딩 중 로컬 변경 보존을 유지한다.
- 테마는 기존 전체 테마 목록을 제공하는 선택 목록을 유지한다.
- 서체·테마 목록은 패널 안에서 펼치고 자체 스크롤 높이를 제한해 작은 화면에서도 전체 목록에 접근할 수 있게 한다. 현재 선택 항목에 초점을 두고 방향키·Home·End·Enter·Escape 조작을 지원한다.
- 테마 선택에는 기존 레지스트리의 배경·강조색 견본을 표시한다. Auto는 기기의 화면 설정을 따른다는 안내를 제공한다.
- 설정 조작부는 본문과 독립적인 기본 UI 서체·글자 크기를 유지한다. 서체 견본은 선택한 서체를 반영한다. 글자 크기의 문장 미리보기 영역은 제거하고, 슬라이더 양 끝에 범위를 표시한다. (2026-10-09 사용자 지정)
- UI의 밝고 어두운 상태색은 사용자가 선택한 앱 테마를 따른다. Auto에서만 시스템 모드에 따라 전환한다. (2026-10-06 사용자 선택 ① 공통 테마 판단 기준 통일)
- 로그아웃은 계정 정보에서 분리해 패널 하단의 조용한 텍스트 행동으로 표시하고 hover·focus에서만 위험 색상을 사용한다.
- 패널의 모든 기능은 키보드로 조작할 수 있어야 하며 열기·닫기 시 포커스를 올바르게 이동·복원한다.
- 기존 사진 업로드·자르기, 환경설정 저장, 저장 실패 입력 보존, 계정별 데이터 격리는 유지한다.

## Codex 구현 판단 · 2026-10-07

- 최초 프리셋과 중간 8~40pt 범위는 후속 사용자 지정으로 대체했다. 현재 슬라이더는 7~20pt, 1pt 간격이며 숫자만 표시한다. 숫자가 바뀔 때 표시 폭이 흔들리지 않도록 같은 폭의 숫자를 사용한다.
- 연속 설정 변경의 서버 저장은 300ms로 묶고 계정 변경·컴포넌트 해제 때 이전 예약을 취소한다. 로컬 값과 화면 변화는 지연하지 않는다.
