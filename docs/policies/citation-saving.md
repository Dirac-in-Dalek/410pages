# 문장 저장과 실패 복구 Policy

## 확정 정책

- 입력 길이와 관계없이 모든 항목을 인용문으로 처리한다. 단어 자동 분류와 단어 전용 객체·화면을 사용하지 않는다. 기존 단어 기록도 인용문으로 처리한다.

- 서재 입력창에서 추가한 새 문장과 단어는 화면에 먼저 표시하고 서버 저장은 이어서 처리한다.
- 서재 입력창에서 생성한 UUID를 데이터베이스 문장 ID로 그대로 사용한다.
- 같은 저장을 다시 시도할 때도 같은 UUID를 사용해 중복 생성을 막는다.
- 서재 입력창은 낙관 행을 만든 즉시 입력란을 비운다.
- 저장 전 초안은 로그인 계정별로 분리해 브라우저 `localStorage`에 보관하고, 책 식별자를 함께 저장한다.
- 새로고침 후 같은 계정으로 접속하면 실패 초안을 복구한다. 같은 UUID의 서버 행이 있어도 사용자가 마지막으로 수정한 로컬 초안을 우선한다.
- 저장에 성공하면 브라우저 초안을 제거한다.
- 저장에 실패하면 내용을 유지하고 사용자가 복사하거나 같은 UUID로 다시 저장할 수 있게 한다.
- 같은 UUID가 서버와 로컬에 모두 있으면 재저장 시 로컬 내용으로 서버 행을 갱신한다.
- 실패 초안을 삭제하면 같은 UUID의 서버 행도 함께 삭제해 다음 조회에서 다시 나타나지 않게 한다.
- 기존의 완전히 같은 문장 중복 4개 그룹은 가장 오래된 행을 남기고 나머지 10개 행을 제거한다.

## 2026-09-13 인용문 편집 화면과 초안 보존

- 승인된 UI 일괄 개선으로 책 화면의 상세 편집을 해당 인용문 위치에서 연다. 전체 화면을 덮지 않는다.
- 상세 편집 중 기존 인용문 메모 패널은 숨긴 채 유지하여 신규·수정·실패 메모 초안을 보존한다.
- 상세의 인용문·출처·페이지·메모 편집값과 저장 중 상태는 로그인 세션 소유의 상태로 관리한다. 검색이나 화면 이동 후 편집을 다시 열어 이어 쓸 수 있다. 서버 자동 저장이나 새 영구 보관 정책을 추가한 것은 아니다.
- 저장 중 재마운트되어도 입력·재전송 잠금을 유지하고 완료 결과를 현재 화면에 반영한다. 저장 중 바깥 클릭 취소는 저장 잠금을 해제하지 않는다.
- 실제 본문 편집을 새로 시작할 때 출처·페이지·본문은 현재 인용문 값을 사용한다. 메모 보기만으로 남은 이전 출처가 이후 이름 변경을 되돌리지 않게 한다.
- 위 내용은 초안 유실·중복 저장 회귀를 막기 위한 구현 기준이다. 사용자가 개별 상태 구조를 직접 지정한 것으로 간주하지 않는다.

## 2026-09-13 위치를 선택한 입력

- 하단 입력창 왼쪽 아래에서 인용문/챕터를 명시적으로 선택한다. 앞선 길이와 관계없는 인용문 처리 규칙은 인용문 모드에서 유지한다. 챕터 모드는 제목을 챕터로 저장하며 인용문을 함께 만들지 않는다.
- 인용문은 선택한 구분선 위치에 바로 생성한다. 페이지 번호는 바꾸지 않는다. 위치를 고르지 않으면 책 최하단을 사용한다.
- 기존 created_at_sort 필드를 최초 저장과 같은 요청으로 전달한다. 최하단 생성 뒤 이동하는 별도 요청을 사용하지 않는다.
- 실패 초안에도 위치를 포함해 새로고침 및 같은 UUID 재시도 뒤 위치를 보존한다.

- 커밋 전 리뷰 보완: 실패 초안의 저자·책을 바꾸면 이전 책 ID와 위치를 함께 초기화한다. 재시도 upsert는 미지정 위치를 null로 보내 부분 저장된 서버 행의 이전 위치도 제거한다. 입력 본문과 페이지는 유지한다.

## 2026-10-06 책 화면 입력창 디자인 선택

- 사용자가 HTML 작업대에서 내보낸 설정을 선택하고 실제 앱 적용을 승인했다. 책 화면에서는 하단 왼쪽에 인용문/챕터를 함께 표시하는 선택형을 쓰고, 오른쪽에 페이지와 원형 체크 저장 버튼을 묶는다.
- 선택 수치는 조작 높이 32px, 페이지·저장 간격 12px, 도구줄 여백 6px, 페이지 폭 124px, 선택형·페이지 모서리 20px이다. 작업대에서 확인한 것처럼 입력창 폭 420px 이하에서는 조작 높이를 44px로 확보하고 오른쪽 묶음을 함께 줄바꿈한다.
- 저장·초안·삽입 위치·페이지·키보드 처리 규칙과 책 화면 밖 입력창의 표현은 유지한다.
- 2026-10-06 후속 시안 선택·구현 승인: 챕터 모드에서만 종류 선택 오른쪽에 단계 화살표를 표시한다. →는 하위, ←는 상위이며 최상위에서는 ←를 숨긴다. 현재 저장된 챕터의 단계 +1까지 하위 챕터를 추가할 수 있고 3단계로 고정한 상한은 두지 않는다.
- 화살표는 배경 없는 Pill 클릭 영역을 쓰고, 단계 변경 시 입력창이 200ms ease-out으로 실제 폭을 바꾼다. 움직임 줄이기 설정에서는 전환을 끈다. 기존 입력·커서·작성 위치·저장 중 잠금은 유지한다.
- 위치 취소 버튼과 중복 상단 문구를 제거한다. 스크린리더에는 삽입 위치 설명을 유지한다. 인용문 모드에는 화살표나 그 빈 공간을 표시하지 않는다.
- 1024px 이상 데스크톱은 기존 인용문·입력창의 공통 읽기 열을 유지한다. 좁은 화면에서는 본문 스크롤바가 차지하는 폭을 하단 입력 영역에도 반영해 실제 글자 영역을 맞춘다.
