# 문장 저장과 실패 복구 Policy

## 확정 정책

- 서재 입력창에서 추가한 새 문장과 단어는 화면에 먼저 표시하고 서버 저장은 이어서 처리한다.
- 서재 입력창에서 생성한 UUID를 데이터베이스 문장 ID로 그대로 사용한다.
- 같은 저장을 다시 시도할 때도 같은 UUID를 사용해 중복 생성을 막는다.
- 서재 입력창은 낙관 행을 만든 즉시 입력란을 비운다.
- 저장 전 초안은 로그인 계정별로 분리해 브라우저 `localStorage`에 보관하고, 책 식별자를 함께 저장한다.
- 새로고침 후 같은 계정으로 접속하면 실패 초안을 복구한다. 같은 UUID의 서버 행이 있어도 사용자가 마지막으로 수정한 로컬 초안을 우선한다.
- 저장에 성공하면 브라우저 초안을 제거한다.
- 저장에 실패하면 내용을 유지하고 사용자가 복사하거나 같은 UUID로 다시 저장할 수 있게 한다.
- 같은 UUID가 서버와 로컬에 모두 있으면 재저장 시 로컬 내용으로 서버 행을 갱신한다.
- 실패 초안을 삭제하면 같은 UUID의 서버 행도 함께 삭제해 다음 조회에서 다시 나타나지 않게 한다.
- 기존의 완전히 같은 문장 중복 4개 그룹은 가장 오래된 행을 남기고 나머지 10개 행을 제거한다.
