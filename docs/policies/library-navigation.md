# 서재 탐색과 책 읽기 Policy

## 확정 정책

- 로그인 후 첫 화면은 저자 홈이다.
- 서재 탐색은 `저자 홈 → 선택한 저자의 책 → 선택한 책의 인용문` 3단계다.
- 저자 홈 첫 타일은 `저자 추가`이며, 같은 이름이 있으면 새로 만들지 않고 기존 저자를 연다.
- 저자 화면 첫 타일은 `책 추가`이며, 새 책은 선택한 저자의 `authorId`에 연결한다.
- 새 책 제목을 입력한 뒤 `시작` 또는 `PDF로 추가하기`로 분기한다.
- 모바일에서는 `PDF 읽기`를 표시하지 않는다.
- PDF 세션은 로그인 사용자별로 분리한다.
- 새 책에서 시작한 PDF 세션과 저장 문장은 해당 `bookId`에 연결한다.
- 데스크톱에서 기존 PDF 세션이 있으면 책을 생성하기 전에 교체 여부를 확인한다.
- 교체를 취소하면 책을 생성하지 않고 기존 PDF 세션을 유지한다.
- 데스크톱 저자별 책 화면에서는 기존 세션의 `읽던 PDF 계속하기`를 제공한다.
- 모바일에서는 `PDF 읽기`와 `읽던 PDF 계속하기`를 표시하지 않는다.
- 탐색은 왼쪽 하나로 통합하며 순서는 `홈 → 최근 책 3권 → 저자와 책 → 폴더`다.
- 왼쪽 트리는 `저자 → 책` 구조이며, 책이 없는 저자도 표시한다.
- 트리에서 저자를 누르면 해당 저자의 책 화면으로, 책을 누르면 해당 책의 인용문 화면으로 이동한다.
- 본문에는 상위 단계로 돌아가는 버튼과 `저자 / 책` 위치 경로를 표시한다.
- 최근 책은 책별 마지막 문장 저장 시각을 기존 `Citation.createdAt`으로 계산하고 상위 3권만 표시한다.
- 문장이 없는 책은 최근 책에 표시하지 않는다.
- 저자는 `AuthorSource.createdAt`과 저장 성공한 문장의 최신 `Citation.createdAt` 중 큰 값으로 최신순 정렬한다. 책 생성, 단어, 저장 중·실패 문장은 저자 순서에 반영하지 않는다.
- 저자 선택 식별자는 `authorId`, 책 선택·필터 식별자는 `bookId`다. 저자 메타데이터의 기준은 `AuthorSource`, 책 메타데이터의 기준은 `BookSource`다.
- 책 화면에서 새 문장을 저장할 때는 현재 선택한 `bookId`를 저장 요청에 직접 포함한다.
- 저자나 책 이름 변경 및 병합 후에는 `books`와 `citations`를 같은 대상 ID와 메타데이터로 갱신한다.
- 같은 이름으로 변경하면 기존 저자 또는 책으로 병합하며, 문장·챕터 블록 이동과 원본 삭제는 단일 DB 작업으로 실행한다. 하나라도 실패하면 병합 전체를 취소한다.
- 홈은 저자를 종이 색인 타일로 표시하고, 저자 화면은 외부 표지 데이터 없이 CSS 책 형태로 책을 표시한다.
- 저자 타일은 장식용 순번을 표시하지 않고 저자 이름을 중앙에 크게, 책 수를 그 아래에 표시한다.
- 저자 홈과 저자별 책 화면의 일반 타일은 데스크톱 hover·키보드 포커스 시 우측 하단 `···`를 표시하고, 모바일에서는 `···`를 항상 표시한다.
- 저자·책 타일의 `···`와 우클릭은 같은 `이름 변경·삭제` 메뉴를 연다. 타일 본문 클릭은 기존 탐색 동작을 유지한다.
- 일반 저자는 사이드바에서 이름 변경·폴더 이동·삭제를 관리하며, 자기 자신 저자는 삭제하거나 폴더로 이동할 수 없다.
- 일반 저자 삭제는 책·인용문·메모·장 구분까지 단일 DB 작업으로 영구 삭제하며, 책·인용문 수를 보여주는 2단계 버튼 확인을 거친다. Undo는 제공하지 않는다.
- 저자 폴더는 기존 인용문 폴더와 별도 데이터이며, 저자 한 명은 하나의 저자 폴더에만 속한다.
- 저자 폴더가 없는 일반 저자는 별도 그룹으로 묶지 않고 `저자와 책` 바로 아래에 일반 저자 행으로 표시한다.
- 저자 폴더는 일반 저자 목록보다 위에 표시한다.
- 폴더 밖 저자를 펼친 폴더 내부에 드롭하면 해당 폴더에 포함하고, 폴더 안 저자를 폴더 밖 저자 영역에 드롭하면 폴더 연결을 제거한다.
- 모바일에서는 저자 행을 길게 누른 뒤 드래그해 저자 폴더에 넣거나 폴더 밖으로 뺀다.
- 저자 관리 메뉴는 이름 변경과 삭제만 제공하며, 폴더 이동 항목은 제공하지 않는다.
- `저자와 책` 제목 오른쪽의 생성 동작은 아이콘과 `폴더 추가` 문구를 함께 표시한다.
- 저자 폴더 이름 변경은 입력·확인·취소를 한 줄에 유지한다.
- 저자 폴더 삭제 시 저자 데이터는 유지하고 폴더 연결만 제거한다.
- 같은 이름의 저자 폴더 생성·변경은 허용하지 않으며 입력 내용을 유지한 오류로 표시한다.
- 동명 저자 병합 시 기존 대상의 폴더를 우선하고, 대상이 미분류일 때만 원본의 폴더를 이어받는다.
- 책 화면은 문장을 카드가 아닌 평면 목록으로 표시한다.
- 단어도 카드가 아닌 문장과 같은 평면 행 목록으로 표시하며, 더블클릭 또는 편집 버튼으로 내용을 수정한다.
- 일반 책 삭제는 해당 책의 인용문·메모·장 구분을 단일 DB 작업으로 영구 삭제하며, 인용문 수를 보여주는 2단계 버튼 확인을 거친다. 삭제된 책의 PDF 세션도 정리하고 Undo는 제공하지 않는다.
- 책 화면의 문장·단어·장 구분은 오래된 항목부터 최신 항목 순으로 고정한다.
- 책 화면의 인용문 입력란은 목록과 분리해 화면 아래에 고정하며, 새 문장은 입력란 바로 위에 표시한다.
- 문장 행을 열면 오른쪽 상세 패널에서 메모·편집·삭제를 수행한다.
- 체크박스 선택과 문장 상세 열기는 서로 다른 동작이다.
- 문장 삭제는 화면에서 즉시 반영하고 5초 동안 `실행 취소`를 제공한 뒤 서버 삭제를 확정한다.
- 여러 문장을 함께 삭제해도 화면에서 즉시 반영하고, 한 번의 `실행 취소`로 전체를 5초 안에 복원한다.
- 책장 조회 실패는 빈 책장으로 표시하지 않는다. 기존 데이터가 있으면 유지하고 오류와 `다시 시도`를 제공한다.
- 저장 실패는 사용자에게 알리고, 문장·메모·책·폴더·장 구분의 입력 내용을 성공 전까지 유지한다.
- 로그인 계정이 바뀌면 이전 계정의 조회 결과·선택·삭제 대기·PDF 화면 상태를 새 계정 화면에 이어서 사용하지 않는다.

## 남은 사용자 결정

- 저장 또는 5초 삭제 대기 중 새로고침·탭 종료가 발생했을 때, 다음 접속에서 자동 재시도할지, 종료를 차단할지, 현재의 최선 시도 방식을 유지할지 결정이 필요하다.
- 기존 중복 저자·책을 정리하고 공백 제거 이름에 유일성 제약을 둘지 결정이 필요하다.
