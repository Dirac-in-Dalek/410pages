# 인증 보안 Policy

## 확정 정책

- 회원가입 전에 이메일의 가입 여부를 별도 조회하지 않는다.
- 회원가입은 Supabase Auth의 가입 결과만 사용하며, 기존 계정의 존재 여부를 공개하지 않는다.
- `check_email_exists` DB 함수는 익명 사용자와 로그인 사용자가 직접 실행할 수 없다.
- 내부 DB 트리거 함수는 Data API에서 직접 실행할 수 없고 고정된 빈 `search_path`를 사용한다.
- Supabase Auth의 유출 비밀번호 차단을 활성화한다.

## 현재 적용 상태

- 유출 비밀번호 차단은 현재 프로젝트의 요금제 제한으로 활성화되지 않았다.

## 남은 사용자 결정

- 유출 비밀번호 차단을 지원하는 요금제로 변경할지, 현재 요금제에서 비밀번호 길이·문자 조합 규칙을 강화할지 결정이 필요하다.
