# 인용문과 댓글 비교 화면 제안

## 사용자 요청

- 댓글 박스와 여백을 줄이고 해당 인용문 가까이에 붙인다.
- 원문과 번역문을 나란히 읽는다.
- 여러 인용문의 댓글을 한 번에 펼치고 다시 접는다.
- 높이 변화는 가능한 한 줄인다.

## 현재 구현의 한계

- 선택한 인용문 한 개만 댓글을 표시한다.
- 댓글이 absolute 위치에 있어 해당 인용문의 행 높이에 반영되지 않는다. 여러 댓글을 동시에 표시하면 다음 행의 댓글과 겹칠 수 있다.
- 댓글 간격 24px, 너비 256px, 입력 박스 여백 12px이며 항상 입력창과 전송 버튼을 표시한다.

## 승인된 화면 방향

- 현재 글꼴·색상·Tailwind 스타일을 재사용한다. 새 디자인 라이브러리를 추가하지 않는다.
- 각 행은 왼쪽 댓글과 오른쪽 인용문의 두 칸이다. 위쪽 정렬선을 맞추고 두 칸 간격은 12px로 줄인다.
- 댓글은 카드 배경 없이 본문 중심으로 표시하고, 입력·편집 중인 영역만 작은 여백을 둔다.
- 책 화면의 `댓글 모두 펼치기 / 댓글 모두 접기`로 저장된 댓글들을 함께 비교한다.
- 전체 표시에서는 저장된 댓글을 읽고, 입력은 선택한 한 인용문에서만 연다. 빈 입력창을 모든 행에 만들지 않는다.
- 추천 높이: 두 칸 중 긴 내용에 맞춰 해당 행만 늘린다. 댓글을 잘라 숨기거나 별도 스크롤하지 않는다.
- 기존 모바일 하단 패널은 유지한다. 기존 홈·메모 자동 접힘은 전체 댓글 표시에도 필요한 공간을 확보하도록 연결한다.

## 높이 선택지

1. 긴 쪽에 행 높이를 맞춤 — 추천. 원문·댓글을 모두 읽을 수 있고 다음 인용문과 겹치지 않는다. 긴 댓글이 있는 행은 높아진다.
2. 인용문 높이 유지, 넘치는 댓글은 `더 보기` — 화면은 짧게 유지된다. 번역문 전체 비교에는 추가 클릭이 필요하다.
3. 두 칸 모두 일정 높이로 접고 `더 보기` — 행 높이는 일정하지만 원문도 일부 숨겨진다.

## 검증 계획

- 전체 표시·개별 입력·긴 번역문·댓글 없는 인용문·챕터 접기와의 조합.
- 원문과 댓글의 상단 정렬 및 다음 행과 겹침 여부.
- 입력·수정 초안 유지와 기존 저장 실패 복구.
- 실제 데스크톱과 모바일 화면에서 확인. 아래 구현 감사에서 검증 결과를 구분한다.


## 구현 감사

- 사용자 결정: 인용문과 댓글을 나란히 표시, 전체 펼치기·접기, 긴 쪽에 맞춰 해당 행 높이 증가, 전체 보기에서는 저장된 댓글을 표시하고 입력창은 선택한 인용문에만 열기.
- Codex 결정: 기존 256px 댓글 너비 유지, 간격 24→12px·입력 여백 12→6px, 한 줄 입력부터 내용에 따라 높이 증가, 짧은 댓글도 원문 가까이 보이도록 댓글 본문 오른쪽 정렬. 기존 글꼴·색상·모바일 분기 재사용.
- Codex 상태 처리: 전체 접기는 현재 입력도 닫는다. 같은 책 화면에서 한 번 연 댓글 패널은 숨겨 유지해 전체 접기와 개별 전환으로 초안이 사라지지 않게 했다. 영구 초안 저장소는 추가하지 않았다. 책 화면을 벗어나거나 새로고침하면 미저장 댓글은 복원하지 않는다.
- Codex 오류 예방: 다른 댓글의 수정·삭제 버튼도 댓글 조작 영역으로 표시하여 pointerdown 외부 닫기로 행 높이가 먼저 변하지 않게 했다. 여러 댓글의 접근성 제목 ID는 React.useId로 구별했다.
- 기존 동작 유지: 서버 저장·수정·삭제 경로, Enter 저장·Shift+Enter 줄바꿈, 모바일 하단 패널, 공간 부족 시 홈→메모 자동 접기, 챕터 접기 범위.
- 실제 화면 검증: 로그인된 로컬 앱에서 전체 펼치기·접기, 개별 입력, 12줄 테스트 초안의 행 높이 증가와 다음 행 비겹침, 전체 접기 후 초안 복원을 확인했다. 테스트 초안은 저장하지 않고 제거했다. 375px 너비에서 모바일 하단 댓글 패널을 확인하고 화면 크기를 복원했다.
- 미검증: 실제 휴대폰 키보드, 서버에 새 댓글을 저장하는 전체 과정, 운영 배포. 이번 시각 검증에서는 기존 사용자 데이터를 수정하지 않았다.
- 남은 사용자 결정: 이번 높이 선택에는 없음. 이전 로고 위치·홈 버튼 위치·챕터 추가 표시·수정·드래그·메모 제목 변경 요청은 후속 항목이다.

- 최종 검증: 관련 테스트 5개 파일 35개 통과, 빌드·타입·공백 검사 통과. 구조 검토에서 발견한 수정 버튼 전환 문제 수정 후 추가 차단 결함 없음. 1200×663 데스크톱에서 가로 넘침 없음, 댓글 전체 펼치기 상태로 로컬 탭을 열어 두었다.

## 댓글 정렬 수정

- 사용자 결정: 인용문 옆 댓글 본문을 왼쪽 정렬한다. 이전 Codex의 오른쪽 정렬 판단을 대체한다.
- Codex 결정: 인라인 댓글 본문의 정렬 클래스만 변경했다.
- 기존 동작 유지: 두 칸 배치·간격·행 높이·댓글 저장·접기와 모바일 표시.
- 미검증: 실제 브라우저에서 수정 후 화면 확인.
- 남은 사용자 결정: 이번 정렬 변경에는 없음.
