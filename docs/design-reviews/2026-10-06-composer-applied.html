Codex가 정한 구현 세부

확인한 결과

실제 앱에서 1024×768의 수치·배치와 가로 넘침 없음, 화살표로 두 종류 전환, 전환 전후 본문·페이지 보존, Enter로 페이지 이동을 확인했습니다. 375px 화면의 입력창 351px에서 44px 조작을 확인했습니다. 320px 화면의 입력창 296px에서는 종류와 오른쪽 묶음이 두 줄로 배치되고 페이지·저장은 같은 줄에 유지됐습니다.

관련 자동 테스트 4개 파일의 10개 시험, TypeScript 검사, 프로덕션 빌드가 통과했습니다. 저장 중 두 종류 잠금·재전송 방지·실패 후 입력 보존·삽입 순서·초안 수명은 자동 테스트로 확인했습니다. 테스트 입력은 비웠고 서버 저장 요청은 보내지 않았습니다.

기존 동작과 미검증 사항

저장 데이터·초안·삽입 위치·챕터 페이지 숨김·기존 키보드 처리와 책 화면 밖 입력창 표현을 유지했습니다. 새 디자인에서의 실제 서버 저장, 물리 터치 기기, 모든 테마의 시각 대조와 오터치 감소 효과는 이번에 검증하지 않았습니다. 남은 디자인 결정은 없습니다.

확인용 임시 화면 크기 설정은 해제합니다. 실제 책 화면·작업대와 기존 개발 서버는 이어지는 주석 작업을 위해 유지합니다. 배포·병합은 수행하지 않았습니다.
