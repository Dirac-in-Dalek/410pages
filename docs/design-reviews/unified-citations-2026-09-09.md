# 단어 분류 제거 — 2026-09-09

## 사용자 결정
- 단어 객체를 없애고 모든 항목을 인용문으로 처리한다.
- 확정 내용은 citation-saving.md에 반영했다.

## Codex 결정
- 단어 길이 분류기와 WordCard/WordCardGroup, 단어 묶음 배치를 제거했다. 모든 항목은 기존 인용문 목록 경로에서 개별 행으로 표시한다.
- 앱의 kind 타입은 sentence만 허용한다. 기존 DB 컬럼·기록은 삭제하거나 일괄 수정하지 않는다. DB의 word 기록과 브라우저의 실패한 word 임시 기록은 읽을 때 sentence로 해석한다. 신규 저장은 sentence로 보낸다.
- 일반 입력, PDF 선택, 임시 표시, 재시도에서 쪽수를 버리는 분기를 제거했다. 짧은 입력도 기존 인용문의 쪽수 입력 단계와 PDF 중복 방지 규칙을 따른다.
- 복사·복구 텍스트는 모든 항목에 기존 인용문 형식(출처·쪽수·선택한 댓글)을 사용한다.
- 최근 읽은 책·저자 순서와 책 문장 수에서도 짧은 항목을 인용문으로 집계한다. 실패·저장 중 기록 제외 규칙은 유지한다.
- 변경으로 폐기된 단어 전용 테스트는 제거하고 입력·쪽수·복사·정렬·복원 회귀 검증을 인용문 통합 정책에 맞췄다.

## 기존 동작 유지
- 원본 ID, 본문, 책·저자 연결, 댓글, 태그, 하이라이트, 이미 저장된 쪽수.
- 인용문의 댓글·편집·삭제·선택·체크박스 표시 규칙, 모바일 기존 인용문 화면.
- 저장 실패 복구, 계정별 임시 기록 분리, 인증/DB 접근 경계.
- 기존 DB에 저장 당시 버려졌던 단어 쪽수를 추정하거나 새로 만들지 않는다.

## 검증
- 전체 63개 테스트 파일, 438개 테스트 통과. 이후 legacy word 임시 기록 복원 테스트를 추가하여 해당 파일을 재검증했다.
- TypeScript 검사, Vite 빌드, diff 공백 검사 통과. 기존 번들 크기/Browserslist 경고는 남는다.
- 로컬 기존 우우우/ㅇㄹㅇㄹ 기록: 문장 선택 체크박스로 렌더링되고 기본 opacity=0 확인.
- check 심층 검토: 이번 범위의 저장·복원·데이터 매핑과 구조에 대해 별도 에이전트 읽기 전용 검토. 새 보안·데이터 손실 차단 이슈 없음.

## 미검증 사항
- 실제 사용자 데이터를 새로 저장·삭제하는 검증과 운영 배포는 수행하지 않았다.
- 실제 PDF 파일에서 새 짧은 선택 저장은 미검증이며 입력 생성 경로는 자동 테스트로 검증했다.
- DB에 남은 과거 word 값은 물리적으로 바꾸지 않았다. 앱 안에서는 모두 인용문으로 처리한다.

## 남은 사용자 결정
