항목별 결과

항목을 누르면 반영 내용이 열린다. 이번 리뷰의 개선안 적용 범위를 기록했다.

  1. U01대기목차 자동 연결＋

    선택 대기. 자동 목차 변환·기존 챕터 결합 규칙을 임의로 적용하지 않았다.

  2. U02대기선택한 챕터 위치에 입력＋

    선택 대기. 작성 시각을 보존하면서 선택 위치에 입력할 구조가 필요하다. DB와 챕터 소속 모델은 변경하지 않았다.

  3. U03반영모바일 챕터 조작을 44px 이상으로 확대＋

    모바일과 터치 입력에서 챕터 추가·이동·수정·삭제를 44px 이상으로 맞췄다. 문장 사이 추가 영역도 넓혔다.

  4. U04반영긴 책 제목 줄바꿈＋

    책 제목의 한 줄 말줄임을 제거했다. 반복 안내를 줄이고 하단 고정 입력은 유지했다.

  5. U05반영모바일 검색 후 결과로 이동＋

    Enter 또는 검색 결과 보기로 탐색창을 닫고 결과 제목으로 초점을 옮긴다. 한글 조합 중 Enter는 제외한다.

  6. U06반영검색 범위 명시＋

    전체·이 저자·이 책·이 폴더의 인용문 검색으로 범위를 표시한다. 검색 대상과 변환 로직은 유지했다.

  7. U07반영키보드용 책 열기 버튼＋

    책 행의 Enter/Space 비활성 규칙을 유지하고 별도 책 열기 버튼을 추가했다. 행은 버튼 대신 그룹으로 안내한다.

  8. U08반영URL 탐색과 뒤로·앞으로·새로고침＋

    저자·책·폴더 ID를 URL에 연결했다. 첫 조회 후 복원하며 뒤로·앞으로·새로고침과 계정 경계를 검증했다.

  9. U09반영한국어 문구와 입력칸 이름 정리＋

    인용문 입력의 접근성 이름을 추가하고 저자·검색 결과·인용문 상세 등 기본 문구를 한국어로 맞췄다.

  10. G01반영실제 실행 설정과 예제 파일＋

    실제 Supabase·YES24 설정을 README와 빈 .env.example에 정리했다. 사용하지 않는 Gemini 설정을 제거했다.

  11. G02반영Git 실행 흔적 정리·시안 보존＋

    실행 흔적 11개의 Git 추적을 끝냈다. 로컬 파일은 유지하고 설정 시안 2개는 문서 이력으로 복사했다.

  12. G03반영기능 코드·테스트 위치 통합＋

    코드·테스트 24개를 기능 폴더로 이동했다. 단순 ReaderScreen 중계를 제거하고 import 경로를 갱신했다.

  13. G04반영기능별 실제 API 구현 이동＋

    실제 API 처리를 shared/api로 옮겼다. lib/api.ts는 기존 호출 호환용 55줄 진입점으로 남겼다.

  14. G05반영생성·병합 처리 분리＋

    저자·책 생성·병합 콜백 4개를 분리했다. 상태·오류 소유자는 유지했다. 기존 큰 훅은 1,104줄에서 871줄로 줄었다.

  15. G06반영문서와 확정 Policy 정합성＋

    README에서 Policy 인덱스로 연결했다. 표지·인용문 통합 설명을 수정하고 챕터의 현재 구현 상태와 이력을 나눴다.

  16. G07반영PDF 지연 로딩·재시도＋

    PDF JavaScript를 분리하고 실패 캐시를 피하는 재요청 주소, 취소·재시도·브라우저 뒤로 가기를 검증했다.

  17. G08반영반복 가능한 브라우저 검사＋

    재실행 가능한 브라우저 검사·전용 설정과 URL·검색·키보드·PDF 회귀 검사를 추가했다. 브라우저 검사의 CI 자동 실행은 아직 연결하지 않았다.

검증 후 화면

로컬 빌드 결과 + 모의 계정·API. 실제 사용자 데이터는 사용하지 않았다. 서비스워커는 검증 브라우저에서 차단했다.
