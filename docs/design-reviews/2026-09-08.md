## 비교 자료

- 2026-09-08 KST에 [Readwise](https://readwise.io/read/)의 Sign in을 눌렀으나 빈 이메일·비밀번호 로그인 양식이 표시됐다. 해당 화면의 스크린샷을 확인했다.
- 실제 읽기·문장·메모 화면에 접근하지 못했으며, 같은 한국어 내용·테마·크기·스크롤 위치의 기준 화면도 없다. 소개 페이지를 비교 대상으로 대체하지 않았다.
- 가독성, 정보 구분, 공간 배분, 시각적 일관성 모두 **비교 보류**다. Readwise보다 우세하다는 결론은 내리지 않았다.

## 수정과 검증

- 원본 1280×715 프레임을 복제했다. 전역 변수와 원본 컴포넌트를 변경하지 않았다.
- 선택된 책 제목 색상을 `#ef233c`에서 `#ff667c`로 변경했다. 배경 `#311116`에서 상대 휘도 공식으로 계산한 대비는 4.0706599147:1 → 6.0895353073:1이다. 일반 글자 4.5:1 기준은 [W3C WCAG 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)을 확인했다.
- 저자명 두 개를 `Yasuhiro Shirai`, `Anil Ansnthaswamy`로 복원하고 텍스트 영역을 105px에서 137px로 늘렸다. 좌측 78px + 폭 137px = 우측 215px로 패널 폭 232px 안에 들어간다.
- 스크린샷 검토와 레이어 재조회로 수정 범위를 확인했다. 원본·수정본 모두 텍스트 35개이며, 바뀐 텍스트는 저자명 두 개, 색상 변경은 선택된 책 제목 하나다. 빈 텍스트는 없다.
- 문장 행 4개 모두 자식 텍스트가 각 행 높이 안에 들어간다. `Anil` 행과 다음 문장은 기존 스크롤 경계에서 일부만 보인다. 전체 화면의 잘림 없음 조건은 통과로 선언하지 않았다.
- Noto Sans KR, 문장 15.04px를 유지했다. 실제 웹의 Pretendard와 다르며 완전한 원본 재현이 아니다.

## 결정 감사

- 사용자 결정: Codex 최종 판정, 매일 실행, 기존 4항목과 완료 조건.
- Codex 결정: 첫 수정 대상으로 선택 글자 대비·저자명 폭을 처리하고, 색상 `#ff667c`와 폭 137px를 선택했다. 실측 부족으로 비교 판정을 보류했다. 이는 기능 확정 Policy가 아니다.
- 기존 동작 유지: 기능·상태·저장·영역 배치·웹 코드·Policy·원본 Figma.
- 미검증 사항: Readwise 동일 조건 비교, 모바일, 키보드, 실제 저장과 탐색. 실제 운영 화면을 오늘 새로 캡처하지 않았으며, 수정 대상은 기존 Figma 원본이다.
- 남은 사용자 조치: Readwise 로그인. 디자인 판정 자체는 Codex가 수행한다. 같은 한국어 내용의 기준 재현이 가능한지도 로그인 후 확인해야 한다.

## 다음 실행

- R1을 중복 생성하지 않는다. Readwise 접근 가능 여부와 기존 실행 결과를 먼저 확인한다.
- 접근이 계속 불가능하고 새로운 개선·근거가 없으면 같은 보고를 반복하지 않는다.
- 비교 기준이 확보되면 기존 4항목으로 판정한다. R1 이후 누적 수정·검증 횟수는 1에서 이어간다.
