# R2 구현 기록 — 완료, 미배포

## 후속 수정 — 좌측 패널 버튼 위치

- 사용자 결정: 전체 메모 패널처럼 좌측에도 명시적인 접기·펼치기 버튼이 필요하다.
- 원인: 기존 버튼은 패널 상단이 아니라 검색창이 있는 상단 줄에 배치되어 있었다.
- Codex 결정: 버튼을 상단 줄 아래로 이동했다. 펼침 상태는 패널 오른쪽에서 16px 안쪽, 접힘 상태는 화면 왼쪽에서 16px 안쪽에 두고 크기는 기존 전체 메모 펼치기 버튼과 같은 40px로 맞췄다. 같은 버튼 요소를 유지해 접기·펼치기 후에도 포커스가 유지된다.
- 기존 유지: 접힘 기억, 자동 접기 순서, 수동 펼침 시 댓글 닫기, 모바일. 새 동작이나 별도 상태를 추가하지 않았다.
- 검증: 관련 테스트 5개·빌드 통과. 실제 로컬 브라우저에서 접기 → 펼치기 버튼 유지 → 재열기와 포커스 유지 확인. y=58.90px, 펼침 x=176px(패널 폭 232px), 접힘 x=16px, 40×40px.
- 미검증: 운영 배포 화면. 현재 코드는 작업 트리에만 있다.
- 남은 사용자 결정: 이번 버튼 위치 수정에는 없음.

## 구현

- 데스크톱 구절 댓글을 왼쪽 홈 패널에서 분리하고 대상 인용문 왼쪽 상단에 배치했다. 기존 댓글 작성·수정·삭제 경로를 재사용한다.
- 댓글과 인용문은 같은 스크롤 영역을 사용한다. 마지막 인용문의 긴 댓글 끝까지 스크롤 가능하다.
- 홈 패널 접기·펼치기를 추가하고 현재 접속의 화면 상태로 보관한다. 책 전환 시 유지하고 계정 변경 시 초기화한다.
- 댓글을 표시할 공간이 부족하면 홈 패널을 자동으로 접는다.
- 사용자가 후속으로 선택한 `1,1` 반영: 홈을 접어도 공간이 부족하면 전체 메모를 자동으로 접는다. 홈을 수동으로 펼치면 댓글을 닫는다. 화면이 넓어져도 홈을 자동으로 펼치지 않는다.
- 책 화면의 제목·저자 표시를 간결하게 정리했고 상위 저자 화면으로 돌아가는 기능은 유지했다.
- 입력 카드 안팎의 중복 구분선·바깥 그림자를 제거했다.
- 정상 저장 중·저장 완료 표시를 제거했다. 기존 실패·복구 처리와 관련 안내는 변경하지 않았다.
- 전체 메모의 기본 파란 포커스 외곽선을 투명하게 하고 텍스트 커서·접근 가능한 입력 이름을 유지했다. 수동 저장 버튼은 보조 색상으로 변경했다.
- 댓글의 공용 스크롤바를 누르면 외부 클릭으로 간주해 댓글이 닫히던 문제를 수정했다.

## 검증

- 전체 테스트: 63개 파일, 435개 테스트 통과.
- npm run build 통과. 기존 큰 청크·Browserslist 알림은 남아 있다.
- npx tsc --noEmit --pretty false 통과.
- 실제 컴포넌트를 연결한 로컬 화면에서 1600px·1280px 검증. 운영 데이터는 수정하지 않고 서버 저장은 대체 콜백을 사용했다.
- 1600px에서 댓글과 인용문 상단은 각각 185.49px. 스크롤 후 각각 -264.51px로 함께 450px 이동했다.
- 1280px에서는 홈이 자동으로 접혔고 댓글·인용문 상단이 모두 185.49px였다.
- 긴 댓글 높이 1110.5px에서 스크롤 끝의 댓글 하단 723.68px, 스크롤 영역 하단 723.50px로 1px 이내에 도달했다.
- 수정 전 스크롤바 클릭으로 댓글이 닫히는 현상을 실제 브라우저에서 재현했다. 수정 후 같은 클릭에도 댓글이 유지됐으며 자동 회귀 테스트를 추가했다.
- 전체 메모 입력 시 outline-color가 rgba(0, 0, 0, 0)이며 파란 선이 나타나지 않는 것을 확인했다.
- 구조 리뷰 추가 결함 없음. 모바일에서 인용문 내부 댓글이 생성되지 않는 테스트 및 기존 모바일 테스트 통과.
- 추가 실제 브라우저 검증: 1087px에서 홈·전체 메모가 접히고 댓글 유지. 1600px로 확장 후에도 두 패널의 접힘 유지. 홈 수동 펼침 후 홈 표시·댓글 닫힘 확인.

## 결정 감사

- 사용자 결정: R2 구현, 데스크톱 댓글 왼쪽 상단 정렬·공동 스크롤, 공간 부족 시 홈 접기, 현재 접속 동안 접힘 기억, 모바일 유지, 정상 저장 상태 표시 불필요, 전체 메모 파란 외곽선 제거. 후속 `1,1`로 전체 메모 자동 접기·수동 홈 펼침 시 댓글 닫기·홈 자동 복원 안 함 확정.
- Codex 결정: 기존 컴포넌트·서체·데이터 경로 재사용, 접힘 상태는 AppShell 소유, ResizeObserver로 화면 공간 확인, 댓글 16rem·간격 1.5rem. 공간 판단에는 기존 읽기 너비 설정의 최솟값 35rem과 바깥 여백 3rem을 사용했다. 공용 스크롤바의 포인터 입력은 외부 클릭 닫기에서 제외했다.
- Codex 세부 결정: 전체 메모를 수동으로 다시 열 때 댓글을 닫아 기존 바깥 클릭 닫기와 키보드 활성화의 결과를 일치시킨다. 자동 접기는 패널을 마운트한 채 폭만 제거하여 진행 중 저장을 유지한다.
- 기존 유지: 사용자 서체 설정, 모바일 댓글 시트, 저장·재시도·삭제 처리, 메모 자동 저장, 오류 복구. Figma의 대체 서체나 예시 문장은 앱에 넣지 않았다.
- 미검증: 운영 서버 저장, 실제 모바일 키보드·터치 기기, 모든 테마·서체 조합.
- 남은 사용자 결정: 이번 R2 구현 범위에는 없음. 배포·병합은 이번 요청에 포함하지 않았다.

## 좁은 화면 결정 이력 — 사용자 1,1 선택 완료

1. 홈을 접어도 공간이 부족할 때: ① 전체 메모 자동 접기(추천), ② 댓글을 인용문 아래로, ③ 가로 스크롤.
2. 자동 접힘 후 수동 펼치기·화면 확장: ① 넓어져도 접힘 유지 / 수동 펼치면 댓글 닫기(추천), ② 넓어지면 자동 펼침 / 부족하면 펼치기 제한, ③ 수동 펼치면 댓글 아래 / 넓어지면 왼쪽 복귀.

두 항목 모두 ①로 확정·구현했다. 수동 홈 펼침 시 댓글을 먼저 닫으므로 다시 자동으로 접히는 문제를 피한다.

## 범위

앱 변경은 작업 트리에만 있다. 배포·병합·커밋은 수행하지 않았다. 설정 패널 재설계와 새 인용문 추가 후 자동 이동은 R2의 확정 범위 밖이며 이번에 임의로 추가하지 않았다. 임시 로컬 점검 화면은 제거했다.
