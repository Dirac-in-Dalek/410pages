키보드로 단계 변경.
둥근 연결선으로 관계 표시.

  1. 01

    제목 맨 앞에서 Tab·Space는 하위, Delete·Backspace는 상위로 변경한다.

  2. 02

    단계와 순서를 저장하며, 챕터 이동 후 관계를 다시 계산한다. 제목 내용과 인용문 위치는 유지한다.

  3. 03

    앱 코드·저장 API·마이그레이션 파일까지 준비했다. 운영 DB 적용·배포는 아직 하지 않았다.

실제 저장에 필요한 파일: 하위 단계 마이그레이션 SQL. 새 필드를 DB에 적용한 뒤 배포해야 한다.

후속 반영: 같은 단계 추가·자동 번호 없음·하위 전체 접기와 연결선 미리보기 수정을 완료했다. 아래 본문은 이전 시점의 기록이다. 최신 결과 보기

드래그로 놓을 위치 미리보기

  • 위아래로 순서, 좌우로 단계를 조절한다.
  • 놓을 위치에 상위 챕터 이름과 둥근 연결선을 표시한다.
  • 놓으면 순서·단계를 함께 저장한다. 제목·인용문 위치는 유지한다.
  • 저장 실패 후 같은 화면에서 다시 드래그할 수 있다. 취소하면 저장하지 않는다.

2026-09-12 개발·빌드 화면에서 실제 마우스 조작과 모의 API 저장·새로고침을 확인했다. 운영 DB와 배포는 변경하지 않았다.

구현한 동작

  • 새 챕터와 기존 제목 편집에서 같은 키 규칙을 적용한다.
  • 제목 중간·선택 범위·조합 중에는 일반 입력을 유지한다. 수정키 조합도 가로채지 않는다.
  • 변경한 제목과 단계는 기존 Enter·저장 버튼으로 함께 저장한다. 실패하면 두 값을 유지하고 재시도한다.
  • 인용문이 없는 챕터 뒤에도 새 하위 챕터를 추가할 수 있다.
  • 부모에서 내려와 하위 앞에서 둥글게 꺾이는 선을 표시한다. 인용문 본문의 왼쪽 정렬은 유지한다.
  • 번호를 자동으로 덮어쓰지 않는다. 아래의 “2장”과 “새 하위”는 검증용 제목을 그대로 표시한 것이다.

앱 화면 확인

빌드된 로컬 앱 + 모의 API. 저장과 새로고침 사이에도 모의 서버의 단계 값을 유지해 API 왕복을 검사했다. 운영 DB 성공을 뜻하지 않는다.

결정 감사

사용자 결정
제목 맨 앞에서만 네 키 적용, 한 단계 밖으로 복귀, 단계+순서 저장, 이동 후 관계 재계산, 참고 이미지의 둥근 연결선. 드래그 중 위치·단계·상위 연결선을 미리 보여주고 놓으면 해당 위치와 단계로 저장.
Codex 결정
드래그의 가로 이동 1rem을 한 단계로 계산하고, 해당 위치에 존재하는 상위 단계까지만 허용한다. 순서와 단계를 한 요청으로 저장하며, 재드래그 시작 시 오류 문구를 유지해 소스 위치가 움직이지 않게 했다. 미리보기는 전체 저장 데이터에 예상 이동을 적용해 관계를 계산한다. depth 필드와 기존 createdAtSort를 사용했다. 단계 필드가 없는 기존 기록은 0으로 읽으며, 순서상 없는 부모 단계는 화면에서 가능한 깊이로 보정하고 원본 값을 자동 수정하지 않는다. 제목과 단계를 기존 저장 경로로 함께 전송한다. 첫 항목·최상위에서 불가능한 이동은 제목을 지우지 않고 유지한다. 선택·조합·수정키 가드를 넣고, 연결선 계산은 부모 요소가 연결된 뒤 수행한다. 선 굵기·곡률·글자 크기를 정했으며 좁은 화면의 제목 폭을 위해 표시 들여쓰기는 최대 3rem으로 압축한다. 데이터 단계 수를 3단계로 제한한 것은 아니다.
기존 동작 유지
제목 내용, 인용문 정렬·위치, 상태 소유자, 계정·책별 저장 범위, 제목만 드래그, 다음 챕터 직전까지 접는 기존 범위. 별도 인용문 소속 필드는 도입하지 않았다.
미검증 사항
운영 DB 적용·배포·실제 계정 저장, 실기기 터치 드래그·한글 IME·모바일 소프트 키보드·Safari·PWA. 조합 이벤트 검사는 실제 운영체제 IME 검증으로 확대하지 않는다.
남은 사용자 결정
새 챕터 추가·Tab의 기본 소속: 사용자의 “선택한 위치의 상위” 교정에 대한 중첩 예시 확인이 남아 있다. 이번 드래그 변경으로 그 규칙을 임의 확정하지 않았다. 번호 자동 표시, 하위를 함께 접는 범위, 실제 목차 변환·기존 챕터 병합, 선택한 챕터에 인용문을 배치하는 나머지 규칙. 키 적용 문맥·단계+순서 저장·연결선 선택은 유지한다.
