책 화면을 ‘댓글 — 인용문 — 메모’ 세 열로 구현

① 데스크톱 책 화면에 선택한 세 열 읽기 구성을 적용합니다.

② 제목·메모 시작점·하단 입력창은 지금까지 정한 정렬을 유지합니다.

③ 기존 저장·초안·댓글·접기 기능을 보존하고 1024px과 4K에서 검증합니다.

앞선 “이제 다 구현하자”는 이 구성의 구현 승인으로 이해했습니다. 지금 요청에 따라 먼저 범위를 정리했습니다. 세 열 제품 구현은 아직 착수 전이며, 화살표 위치와 ‘메모’ 문구는 앞선 작업에서 로컬에 반영된 상태입니다.

왼쪽 · 문장별 댓글

해당 인용문과 나란히 표시하고 함께 스크롤합니다.

가운데 · 책 제목과 인용문

책 제목의 왼쪽 시작선은 인용문 글자 시작선과 같습니다.

하단 입력창도 저장될 문장의 단계·폭을 따릅니다.

오른쪽 · 메모

카드 대신 긴 글이 이어집니다. 메모 본문의 첫 줄은 첫 인용문 상단에서 시작합니다.

1. 화면에서 바뀌는 것

항목구현 내용
적용 화면1024px 이상 데스크톱의 책 상세 화면. 1024×768 노트북도 데스크톱 구성을 사용합니다.
세 열 배치왼쪽 댓글, 가운데 인용문, 오른쪽 메모를 하나의 읽기 묶음으로 배치합니다. 4K에서도 메모가 화면 오른쪽 끝으로 멀어지지 않도록 묶음의 최대 폭을 제한합니다.
양쪽 거리인용문 글자 영역에서 왼쪽 댓글과 오른쪽 메모까지의 거리를 맞춥니다. 세 열의 폭을 똑같이 만들지는 않습니다.
책 제목제목·저자·목록 조작을 가운데 인용문의 글자 시작선에 맞춥니다.
메모 표현오른쪽 사이드바 카드의 배경·테두리·고정 푸터를 제거하고, 인용문과 어울리는 글자 크기·서체·행간으로 긴 글을 표시합니다. 저장 안내와 재시도 조작은 유지합니다.
메모 시작점메모 제목이 아니라 메모 본문 첫 줄을 첫 인용문 본문 상단에 맞춥니다. 이 초기 여백도 메모와 함께 스크롤되어, 아래로 스크롤하면 글이 메모 열 최상단까지 올라옵니다.
스크롤댓글과 인용문은 같은 행에서 함께 스크롤합니다. 메모는 오른쪽 열에서 독립적으로 스크롤합니다.
접기·펼치기상단 ‘메모’ 버튼으로 접고 다시 엽니다. 메모를 접거나 펼쳐도 인용문 위치·입력 내용·메모 초안을 유지합니다. 세 열이 함께 열릴 공간이 부족하면 서재를 자동으로 접는 작업대 방향을 적용하며 수동 서재 조작을 유지합니다.
화면 문구패널 제목과 상단 버튼은 ‘메모’. 책별 저장 범위는 유지하며 접근성 설명에는 범위를 남깁니다.
하단 입력창인용문/챕터 선택, 페이지, 원형 체크 저장을 유지합니다. 챕터에서만 배경 없는 화살표를 박스 바깥 왼쪽에 두고, 인용문·챕터 선택 버튼과 같은 높이에 정렬합니다.
계층 작성→ 하위 / ← 상위, 최상위에서 ← 숨김, 현재 챕터 단계 +1까지 이동을 유지합니다. 저장 후 인용문 모드로 돌아와 같은 소제목 아래에 이어 쓰며, 입력창은 저장될 인용문과 같은 시작선·폭을 사용합니다.

2. 구현에 사용할 기준값

작업대의 ① 묶음 중심안을 기준으로 잡겠습니다. 아래 숫자는 현재 추천 기본값이며, 사용자가 숫자 하나하나를 별도로 지정한 것으로 기록하지 않습니다.

기준값과 적용 방식
열의 초기 최대 폭댓글 240px / 인용문 592px / 메모 360px
열 사이 간격양쪽 40px. 가용 공간이 부족하면 열 폭과 간격을 함께 조정합니다.
1024px서재를 접고 세 열을 가용 폭에 맞춥니다. 작업대 기본값 실측은 댓글 약 193px / 인용문 430px / 메모 298px입니다. 실제 앱의 스크롤바·서재 너비를 반영해 같은 관계를 맞춥니다.
넓은 화면설정한 읽기 폭을 유지하고 남는 공간은 묶음 바깥의 여백으로 둡니다.
기존 폭 조절서재와 메모의 드래그 폭 조절 기능을 보존하되 새 읽기 열의 실제 가용 공간 안에서 계산합니다. 예전 사이드바의 저장된 폭 때문에 인용문이 과도하게 좁아지지 않도록 제한합니다.
단계 전환입력창의 실제 폭 변화는 200ms ease-out. 움직임 줄이기 설정에서는 전환을 끕니다.

3. 반드시 보존할 기능

  • 책마다 하나인 메모, 800ms 자동 저장, 지금 저장·재시도, 저장 중 잠금과 계정·책별 초안 복구.
  • 메모를 접은 동안 진행 중인 자동 저장과 초안 보존.
  • 댓글 추가·수정·삭제, 전체 펼치기·접기, 선택한 문장의 댓글 입력, 메모 영역을 눌러도 댓글 초안이 사라지지 않는 동작.
  • 챕터·인용문 삽입 위치, 저장 후 이어 쓰기, 페이지 입력, 커서·한글 조합·키보드 조작.
  • 모바일의 기존 댓글·메모 하단 시트. 데스크톱 재설계를 모바일에도 강제로 적용하지 않습니다.
  • Day/Night 및 기존 테마·글자 크기 설정, 책 이동·검색·저장 실패 상태.

5. 완료를 판단할 확인 항목

  1. 1024×768 / 1440 / 1920 / 4K: 댓글·인용문·메모의 거리, 제목 시작선, 글자 잘림·겹침, 전체 여백 확인.
  2. 첫 화면과 스크롤: 첫 인용문과 메모 본문 시작 높이 일치, 메모 여백이 함께 스크롤되어 최상단까지 올라오는 동작 확인.
  3. 접기와 화면 전환: 메모·서재·댓글 접기, 책 이동 후 복귀, 저장 중·실패·복구에서 입력·초안·읽기 위치 확인.
  4. 계층 작성: 챕터·인용문 전환, 하위·상위 이동, 소제목 저장 후 연속 인용문 저장, 같은 단계의 입력·등록 문장 폭 확인.
  5. 표시 환경: Day/Night, 큰 글자, 빈 책·긴 메모·여러 댓글, 모바일 기존 시트 확인.
  6. 회귀 검사: 관련 저장·초안·레이아웃 테스트, 타입 검사·빌드, 시안과 실제 앱 비교. 예제 저장과 실제 서버 저장의 검증 수준을 구분합니다.
