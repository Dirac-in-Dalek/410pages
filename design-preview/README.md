# 410pages 웹 디자인 시스템 선택 가이드

세 안은 같은 React 컴포넌트와 예제 기록을 사용합니다. 비교 화면에서 안을 고르면 해당 영역의 색상, 버튼 크기, 라운드, 여백과 표면이 함께 바뀝니다. 운영 기준 화면은 커밋 `341e4eb`입니다.

**1안**은 지금의 로그인 버튼과 같은 빨강으로 주요 행동을 찾기 쉽습니다. 선택과 오류가 함께 보이는 화면에서는 오류 문장과 아이콘이 구분을 돕습니다. **2안**은 짧은 간격과 각진 모서리로 서재 목록을 촘촘하게 보여 줍니다. 글자와 주요 버튼이 같은 잉크색이므로 채움과 윤곽으로 행동의 중요도를 구분합니다. **3안**은 큰 조작 영역과 넓은 패딩으로 읽기 영역과 조작 영역을 뚜렷하게 나눕니다. 작은 화면에서는 한 번에 보이는 내용이 줄어들 수 있습니다.

## 조합과 재사용

| 웹사이트에서 할 일 | 사용할 부품 | 사용 기준과 예외 |
|---|---|---|
| 로그인, 저자 이름, 책 제목 입력 | Field, ActionButton | 입력 위에 13px 라벨, 7px 간격, 최소 50px 입력 높이, 6px 라운드와 16px 입력 글자. 오류 문구는 해당 입력에 연결합니다. 로그인은 밝은 모드입니다. |
| 서재에서 저자와 책 찾기 | SearchField, BookCard, ActionMenu | 검색은 서재 범위를 이름으로 알려 줍니다. 결과 선택과 편집·삭제 메뉴는 독립된 조작입니다. 책 표지 이미지가 없으면 책 제목과 저자명을 표시합니다. |
| 챕터와 문장 읽기 | ChapterRow, CitationRow, IconButton | 독서 본문이 먼저 읽히게 두고 쪽번호와 메모는 보조 정보로 둡니다. 토글 버튼에는 선택 상태를 전달합니다. |
| 인용문 메모와 책 전체 메모 편집 | MemoField, Panel, Notice | 메모 종류를 라벨로 구분합니다. 입력·저장·재시도 상태는 실제 호출부가 소유합니다. 실패는 문구와 재시도 행동으로 표시합니다. |
| 외관, 글자 크기와 선택 항목 | Choice, SelectField, Panel | 상호 배타적인 값에는 라디오 또는 선택 메뉴, 독립적인 값에는 체크박스나 스위치를 사용합니다. |
| 삭제, 복사 및 취소 | ActionMenu, Dialog, Notice | 삭제는 명시적인 문구로 표시합니다. 결정을 요구하는 대화상자는 이름, 취소, 확인을 제공하고 닫힌 뒤 진입점으로 돌아갑니다. |

**웹 상호작용.** 주소가 있는 이동은 링크로, 저장·펼치기·취소는 버튼으로 연결합니다. 키보드 Tab으로 순서대로 접근하고 Enter/Space로 버튼을 작동시킵니다. 호버와 눌림은 피드백을 주며, 키보드 포커스는 배경과 구분되는 외곽선으로 표시합니다. 처리 중에는 중복 실행을 막고 행동 이름을 유지합니다. 선택·오류·비활성은 색 외에 문구나 상태 속성으로도 구분합니다.

**모바일.** 미리보기는 각 예시 화면의 내부 폭 1024 CSS px부터 데스크톱 구조를 사용합니다. 나란히 보기에서는 각 안을 좁은 화면으로, 크게 보기에서는 브라우저 폭에 맞춰 확인할 수 있습니다. 터치 조작은 최소 44px로 잡고, 320px 폭에서는 버튼 묶음이 줄을 바꾸고 메모와 보조 도구가 본문을 밀어내지 않도록 배치합니다. 아이콘의 그림 크기와 버튼을 누르는 크기를 따로 정합니다. 사용자가 브라우저나 본문 글자를 키워도 긴 저자명·책 제목·오류는 필요한 만큼 줄을 바꿉니다. 동작 줄이기 설정에서는 이동 애니메이션을 생략합니다.

**브랜드와 서체.** 헤더 워드마크는 기존 BrandWordmark의 Biblioteca Bold 윤곽을 사용합니다. 로그인은 현재 책 심벌, 스페인어 제목과 버턴 인용·출처를 따릅니다. 조작 글꼴은 Pretendard 계열, 읽기 본문은 사용자 선택 서체와 크기를 연결합니다. CSS 변수 전체는 `shared/ui/design-system/tokens.css`에서 확인할 수 있습니다.

## 실제 코드에 연결하는 순서

1. 선택한 페이지의 경계에 DesignSystem을 한 번 두고 안과 밝기를 전달합니다. 선택값은 호출부에서 결정합니다. 계정에 저장된 실제 테마 ID는 그대로 사용할 수 있습니다.
2. 로그인에서는 `features/auth/ui/Auth.tsx`의 기존 인증 처리와 입력 상태를 유지하면서 이메일과 비밀번호 UI에 Field를 연결합니다. 비밀번호 표시, 자동완성, 필수 입력 의미를 보존합니다.
3. 서재는 `LibraryCardGrid`의 저자·책 선택과 `ProjectSidebar`의 탐색을 연결합니다. 읽기 화면은 `ChapterBlockCard`, `CitationCard`, `BookMemoPanel`의 조회·저장·실패 복구 로직을 유지하면서 해당 표시 부품을 사용합니다. 설정에서는 `SettingsSelection`의 현재 값과 변경 함수를 전달합니다.
4. 상태와 이벤트는 화면에서 관리합니다. 스킨 교체는 CSS 토큰을 통해 이루어지고, 데이터 요청이나 사용자 설정 마이그레이션은 비교 부품이 수행하지 않습니다.
5. 새 부품을 추가할 때는 같은 역할의 기존 부품, 상태별 예시, 모바일·키보드 동작, 사용 예를 함께 검토합니다. 규격 변경은 토큰과 이 비교 화면에서 먼저 확인합니다.

## 로컬에서 실행

저장소의 Node 24 환경에서 `npm ci` 후 `npm run dev -- --host 127.0.0.1`를 실행하고 브라우저로 `/design-preview/`를 엽니다. 예제 진입점은 별도로 구성했으며 제품의 기본 빌드는 기존 진입점을 사용합니다. 전달한 오프라인 HTML은 개발 서버 없이 브라우저에서 바로 열 수 있습니다.

검토 시 같은 책으로 1·2·3안의 기본 버튼과 보조 버튼, 한 문장 주변의 여백, 오류와 포커스, 좁은 화면과 어두운 배경을 비교하세요. 최종 선택과 적용 범위는 별도 결정입니다.
